# M-39(feat): 完成 K 线策略信号与缓存模式调整

OpenSpec Change: update-kline-strategy-controls

## 背景:

- K 线图表原有 `B/S` 信号和策略回测信号可能同时展示，用户难以区分指标信号与策略历史信号。
- 策略回测面板维护独立开始日期和结束日期，容易与顶部 K 线 query 日期范围不一致。
- 历史 K 线缓存列表缺少每行数据源信息，且默认批量准备多周期、多复权组合，请求范围偏大。

## 方案概述:

- 在 K 线指标设置中新增默认关闭的 `策略` 信号开关，并与 `B/S` 保持互斥。
- 策略回测统一使用当前 K 线 query 的数据源、证券、周期、复权和日期范围，删除策略面板独立日期输入。
- 历史 K 线缓存弹窗新增 `数据源` 列，并区分 `单只股票缓存` / `多只股票缓存`；每次打开默认单只模式，默认仅勾选 `日线` 和 `前复权`。
- 归档 OpenSpec change，并同步更新 `chart-indicators`、`help-and-updates`、`kline-strategy-backtesting`、`stock-workspace` 主 spec。

## 实现改动:

- 新增 `strategySignal` 指标定义、旧设置 normalize 兼容和 `B/S` / `策略` 互斥逻辑，图表 adapter 仅在策略开关开启且 `B/S` 关闭时渲染策略信号。
- 移除策略设置运行态 `dateRange`，保留旧字段读取兼容但不再写回；回测 query 改由当前 K 线 query 派生，并保留缓存非交易日边界容忍逻辑。
- 历史 K 线缓存弹窗新增数据源展示列和缓存对象模式控件；单只模式使用当前证券，多只模式使用自选股列表，空列表禁用刷新。
- 缓存默认 query 调整为 `day + qfq`，切换模式时保留数据源、日期范围、周期和复权选择，同时清空选中行并重新加载状态。
- 更新 README、应用内使用说明书、CHANGELOG 和相关单元测试，归档 OpenSpec artifacts。

- 历史 K 线缓存弹窗：验证默认单只股票缓存、默认日线前复权、数据源列、切换多只模式和空自选股禁用刷新。

## 调查结论:

- 归档时 OpenSpec CLI 先后提示两个 delta spec 场景标题缺失风险，已把旧场景标题保留并改写为新规则，避免归档覆盖主 spec 时丢失场景。

## 风险与后续:

- `策略` 开关默认关闭，用户运行回测后如果需要在图表查看策略信号，需要手动在 K 线指标中开启。
- 多只缓存需要用户显式切换到 `多只股票缓存`，避免误触发大批量缓存任务；后续如需要可再规划数据源筛选或新增第三方数据源。
