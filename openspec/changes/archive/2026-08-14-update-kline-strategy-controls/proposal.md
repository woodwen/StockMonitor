## Why

当前 K 线指标里的 B/S 信号和策略回测信号会同时出现在图表上，用户难以区分当前指标信号与选中策略的历史信号。策略回测面板还维护独立的开始日期和结束日期，容易与外部 K 线日期范围不一致，增加理解和使用成本。

## What Changes

- 在 K 线指标设置中新增 `策略` 信号开关，用于控制选中策略的图表信号标记是否展示。
- `策略` 信号开关默认关闭，以保留当前 K 线 `B/S` 默认开启的既有体验。
- K 线 `策略` 信号开关与 K 线 `B/S` 信号开关互斥：开启其中一个时，系统应关闭另一个，避免图表同时渲染两套买入/卖出标记。
- 移除策略回测面板中的独立回测开始日期和结束日期输入，策略回测统一使用外部 K 线 query 的日期范围。
- 本 change 将需求中的“回撤设置”按“策略回测设置”处理，不调整最大回撤指标算法或展示口径。
- 策略结果展示、缓存读取、错误提示和持久化逻辑应以当前 K 线 query 的 `startDate` / `endDate` 为准。
- 不新增策略信号样式配置，不调整策略算法、评分公式或成交模型。
- 历史 K 线缓存列表新增 `数据源` 列，显示每行缓存 query 对应的数据源名称，例如 `东方财富`；默认列位置为 `名称` 后、`周期` 前，默认列宽为 96px，未知数据源显示原始 `sourceId`。
- 历史 K 线缓存列表不新增数据源筛选、排序或分组能力；本次只增加展示列。
- 历史 K 线缓存弹窗顶部区分 `单只股票缓存` 与 `多只股票缓存` 两种模式，每次打开默认使用 `单只股票缓存`，不记忆上次模式选择。
- `单只股票缓存` 只针对当前 K 线 query 的证券准备缓存，即使该证券不在自选股列表中也可缓存；`多只股票缓存` 针对当前自选股列表，列表为空时展示空状态并禁用刷新。
- 切换缓存模式时保留当前数据源、日期范围、周期和复权选择，清空表格选中项并重新查询缓存状态；`刷新全部` 在单只模式只刷新当前证券，在多只模式刷新当前自选股列表。
- 历史 K 线缓存弹窗默认只勾选 `日线` 与 `前复权`，`周线`、`月线`、`不复权`、`后复权` 默认不勾选，用户可按需手动扩展。
- 更新 README 和应用内使用说明书，说明策略信号开关、B/S 互斥行为、策略回测日期范围来自外部 K 线设置、历史 K 线缓存的单只/多只模式和默认缓存选择。

## Capabilities

### New Capabilities

- 无

### Modified Capabilities

- `chart-indicators`: K 线指标设置新增策略信号开关，并约束其与 B/S 信号开关互斥。
- `kline-strategy-backtesting`: 策略回测区间不再由策略面板单独设置，改为继承当前 K 线 query 的日期范围。
- `stock-workspace`: 工作区不再恢复或保存独立策略回测区间，由 ViewModel 编排策略信号开关与图表标记同步，并在历史 K 线缓存列表展示数据源列，支持单只/多只 K 线缓存模式和新的默认缓存选择。
- `help-and-updates`: README 和应用内使用说明书需要同步新的 K 线指标与策略回测使用方式。

## Impact

- 影响 renderer 工作区 ViewModel、K 线指标设置 model、K 线策略面板、K 线图表 adapter 的信号渲染开关编排。
- 影响历史 K 线缓存弹窗表格列定义，需要从每行 query 的 `sourceId` 映射到数据源显示名。
- 影响历史 K 线缓存弹窗的默认查询条件、模式切换状态和请求构造，需要区分当前单只证券缓存与自选股多只缓存，且默认只请求日线前复权。
- 影响策略回测设置的 normalize、持久化迁移和回测 query 组装逻辑，旧版已保存的策略区间字段应兼容读取但不再驱动 UI 或回测请求。
- 影响相关测试，包括 K 线指标设置互斥、策略回测 query 日期来源、ViewModel 编排、图表信号渲染和用户文档校验。
- 影响 `README.md`、应用内 `使用说明书`，以及按项目规则记录用户可见变更的 `CHANGELOG.md`。
