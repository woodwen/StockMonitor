# M-3(feat): 接入远端行情数据源与代理配置

## 背景

- 原应用依赖本地行情文件导入，用户需要手动准备数据文件，无法直接检查远端数据源可用性。
- 本期目标改为使用开源免费远端行情接口，覆盖沪深京股票、ETF、指数。
- 接入后发现东方财富、网易财经 163 在当前网络环境下存在可用性问题，需要数据源测试和显式代理配置入口。

## 方案概述

- 接入东方财富、新浪财经、网易财经 163、腾讯/QQ 财经四个数据源。
- 默认使用东方财富，支持在“数据源”弹窗内测试请求状态并切换源。
- 移除本地文件兜底，应用启动和刷新只走远端行情源。
- 默认所有行情请求直连，不读取环境代理变量。
- 新增“代理”弹窗，支持 SOCKS5/HTTP 代理配置，保存后影响后续远端行情请求。

## 实现改动

- 新增主进程远端行情源模块，统一处理数据源能力、请求、解析和标准化输出。
- 新增数据源列表、远端行情查询、代理配置保存 IPC。
- 新增 Electron 数据 adapter，替换本地文件 adapter。
- 顶部工具栏新增“数据源”和“代理”入口，保留证券代码、周期、复权、日期范围和刷新能力。
- 数据源弹窗支持展示请求状态、错误详情、记录数、耗时，并在弹窗内切换当前源。
- 代理弹窗支持启用/关闭代理、选择 SOCKS5/HTTP、配置地址和端口。
- 移除本地文件导入 view model、文件读取工具、最近文件存储、文件菜单入口和打包内置示例数据配置。
- 更新 README 和 feature plan，补充远端数据源、代理配置和东方财富失败调查结论。

## 测试计划(UT)

- 覆盖远端数据源元信息，确保四个源均可列出且能力声明符合第一期范围。
- 覆盖远端返回解析，验证 mock 数据可转换为统一 StockDataset。
- 覆盖默认网络策略，确保存在 HTTP_PROXY 环境变量时默认请求仍不走环境代理。
- 覆盖网易财经 163 能力限制，查询指数/ETF 时在请求前返回不支持错误。
- 覆盖 StockWorkspaceViewModel 默认查询、刷新成功、数据源测试、数据源切换、代理配置保存。
- 保持指标计算、K 线图 adapter、旧解析器回归用例通过。

## 影响范围(建议手动测试范围)

- 启动应用，确认默认使用东方财富加载 sh000001。
- 分别输入沪市股票、深市股票、北交所股票、ETF、指数，验证刷新和图表展示。
- 打开“数据源”弹窗，测试东方财富、新浪财经、网易财经 163、腾讯/QQ 财经的请求状态。
- 在“数据源”弹窗中切换到新浪财经或腾讯/QQ 财经，确认刷新使用新源。
- 打开“代理”弹窗，分别启用 SOCKS5、HTTP、关闭代理后重新测试数据源。
- 切换日线、周线、月线、分钟线和复权选项，确认不支持项展示明确错误。
- 打开/关闭 BOLL、VOL MA、B/S，确认远端数据加载后指标展示正常。
- 网络失败时，确认顶部错误提示和底部状态栏展示一致。

## 调查结论

- 东方财富 K 线接口路径和核心参数符合公开常见用法，当前失败不是 URL 或参数实现错误。
- 当前网络下访问东方财富 push2/push2his API 会出现服务端空响应，Electron session.fetch 可稳定复现 net::ERR_EMPTY_RESPONSE。
- 东方财富官网页面 quote.eastmoney.com 可正常返回 200，失败集中在 push API 域名。
- 网易财经 163 当前仅按股票日线能力接入，指数/ETF 会提前返回不支持错误。

## 风险与后续

- 公开免费接口稳定性、反爬规则、返回字段都不受应用控制。
- 东方财富作为默认源在部分网络环境下可能不可用，用户可通过“数据源”弹窗切换到新浪财经或腾讯/QQ 财经。
- 后续可增加数据源健康缓存、失败源自动降级、数据源优先级配置和接口返回字段监控。

## 验收标准

- 默认启动和刷新不再读取本地行情文件。
- 顶部存在“数据源”和“代理”两个入口。
- 数据源弹窗可以测试四个源，并可以完成数据源切换。
- 代理弹窗可以保存 SOCKS5/HTTP 代理配置，并影响后续远端行情请求。
- 默认不启用代理时，不读取环境代理变量。
- UT、类型检查、构建均通过。
