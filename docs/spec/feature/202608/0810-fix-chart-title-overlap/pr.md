# M-4(docs): 补充图表标题重叠修复计划

## 背景

- K 线图左上角曾同时展示自定义股票标题和 klinecharts 内置指标 legend。
- 自定义标题使用绝对定位叠加在图表区域内，与 `BOLL(20,2)`、`UP/MID/DN` 等 legend 信息发生视觉重叠。
- 需要补充本次修复的设计说明、影响范围和验收标准，便于后续回归和评审。

## 方案概述

- 新增 feature plan 文档，记录图表标题与指标信息重叠问题的原因和修复方案。
- 方案采用最小 UI 调整：移除图表内标题叠加层，将股票标题移到顶部工具栏。
- 明确不改变 klinecharts 指标绘制、数据加载、指标计算和 Electron IPC 逻辑。

## 实现改动

- 新增 `docs/spec/feature/202608/0810-fix-chart-title-overlap/plan.md`。
- 文档包含背景、方案概述、问题定位、实现改动、测试计划、手动测试范围、风险与后续、验收标准。
- 记录图表视图、顶部工具栏和样式三个涉及模块的预期改动点。

## 测试计划(UT)

- 文档本身不新增 UT。
- 计划文档中要求布局改动验证执行：
  - `yarn typecheck`
  - `yarn build`
- 本次提交前按项目提交流程执行：
  - `yarn typecheck`
  - `yarn test`
  - `yarn build`
  - `git diff --check`

## 影响范围(建议手动测试范围)

- 启动应用，确认图表左上角不再出现股票标题与 BOLL legend 重叠。
- 确认当前股票标题在顶部工具栏显示。
- 缩小窗口宽度，确认标题单行省略且不挤压工具栏控件。
- 打开/关闭 `BOLL`、`VOL MA`、`B/S`，确认图表区域没有新的重叠。
- 点击“示例”或导入行情文件，确认标题随数据集更新。

## 风险与后续

- 当前文档只覆盖图表标题重叠修复，不处理 klinecharts 内置 legend 的自定义布局。
- 后续如果顶部工具栏继续增加控件，需要重新评估工具栏标题的压缩策略。
- 后续如需在图表区展示更多自定义信息，应避免继续使用绝对定位覆盖 legend 区域。
