# 帮助菜单使用说明书

## 背景

当前应用已经在主窗口顶部工具栏和 README 中说明了分时、K 线、数据源、指标、自选股、网络代理和自动更新能力，但桌面应用内的“帮助”菜单只有“检查更新”和“关于 Stock Monitor”：

- 新用户需要离开应用去 README 中查找操作说明。
- 打包后的离线场景下，用户无法稳定访问项目仓库文档。
- README 同时包含开发、架构、打包和验证内容，不适合作为用户操作手册直接展示。

本次目标是在“帮助”菜单中新增“使用说明书”入口，提供面向普通用户的离线操作说明。

## 方案概述

采用当前主窗口内弹出说明书 Modal 的方案：

- 在 `帮助` 菜单中新增 `使用说明书`。
- 点击后由 main process 通过既有 `menu:command` 通道通知 renderer。
- renderer 在当前主窗口内打开 Ant Design Modal。
- 说明书内容内置在 renderer 组件中，随应用打包离线可用。
- 首版只提供结构化文字和目录，不放截图、不联网、不新增搜索和快捷键。

不采用独立 `BrowserWindow` 或外部链接，避免增加窗口生命周期、打包资源路径、外链可用性和跨窗口样式维护成本。

## 范围边界

本次包含：

- 新增 `帮助 -> 使用说明书` 菜单入口。
- 新增离线内置说明书 Modal。
- 说明书覆盖当前用户常用功能和常见问题。
- 补齐菜单命令、preload 类型、Root ViewModel 状态和 UI 挂载。
- 补齐 README、CHANGELOG、方案文档和 PR 记录。
- 补齐菜单入口和 Root ViewModel 状态测试。

本次不包含：

- 不新增独立帮助窗口。
- 不打开外部浏览器或 GitHub README。
- 不增加截图、搜索、快捷键、多语言或远程文档加载。
- 不调整现有行情、指标、自选股、代理或更新逻辑。

## 内容结构

说明书首版包含以下章节：

1. 免责声明
   - 行情数据来自公开网页接口或第三方服务，可能延迟、缺失、错误或不可用。
   - 技术指标和 B/S 标记仅用于行情展示和程序化计算验证。
   - 不写投资建议、买卖建议、荐股服务、收益承诺或类似表述。

2. 快速开始
   - 输入证券代码。
   - 按 Enter 或点击“刷新”。
   - 在“分时 / K线”之间切换视图。
   - 通过状态栏查看当前数据源、记录数、加载状态和更新状态。

3. 证券代码格式
   - 支持 `sh`、`sz`、`bj` 前缀。
   - 示例：`sh000001`、`sz399001`、`sh600519`、`sz000001`。
   - 建议指数显式输入前缀，避免代码歧义。

4. 分时视图
   - 展示价格线、均价线、昨收线、成交量和分时指标。
   - 支持十字线、tooltip 和分区图例。
   - 窗口可见且处于 A 股交易时段时自动静默刷新。
   - 分时视图只允许切换到支持分时能力的数据源。

5. K 线视图
   - 支持日线、周线、月线和分钟线周期。
   - 支持不复权、前复权、后复权；不支持复权的数据源会自动收敛到不复权。
   - 支持日期范围、主图指标和副图指标。
   - K 线由用户手动刷新。

6. 指标设置
   - 入口为顶部工具栏“指标”。
   - K 线和分时使用独立指标配置，互不覆盖。
   - 参数会做范围校验。
   - 副图指标数量存在上限。

7. 自选股
   - 入口为顶部工具栏“自选”。
   - 支持单只添加、批量粘贴、管理模式删除所选。
   - 点击自选股会切换当前证券代码并刷新当前视图。
   - 自选股列表保存到本地设置，应用重启后恢复。

8. 数据源
   - 入口为顶部工具栏“数据源”。
   - 弹窗可测试各数据源请求状态、耗时、记录数和分时能力。
   - K 线和分时数据源独立保存。
   - 免费网页接口不提供稳定 SLA，请以弹窗测试结果和状态栏提示为准。

9. 网络代理
   - 入口为顶部工具栏“代理”。
   - 默认直连，不读取系统代理环境变量。
   - 可手动启用 SOCKS5 或 HTTP 代理。
   - 代理设置同时影响行情请求和更新检查。

10. 应用更新
    - 菜单入口：`帮助 -> 检查更新`。
    - 工具栏入口：`检查更新`。
    - 可通过“启动检查更新”开关控制启动后是否自动检查。
    - 有新版本时提示下载，下载完成后提示重启安装。

11. 常见问题
    - 无数据：检查证券代码、当前视图、数据源能力和日期范围。
    - 请求失败：打开“数据源”弹窗测试其他数据源，或检查网络代理配置。
    - 分时没有自动刷新：确认窗口可见、处于交易时段，且当前视图为分时。
    - 更新检查失败：检查网络、GitHub Releases 可访问性和代理配置。

## 实现改动

### 菜单入口

修改 `src/main/menu.ts`：

- 在“帮助”菜单中新增 `使用说明书`。
- 点击后发送 `open-user-manual` 菜单命令。
- 保留现有 `检查更新` 和 `关于 Stock Monitor` 行为。

### Preload 类型

修改 `src/preload/stock-api.ts`：

- 将 `MenuCommand` 扩展为：

```ts
export type MenuCommand = 'refresh-stock' | 'check-update' | 'open-user-manual'
```

`src/preload/index.ts` 继续复用现有 `onMenuCommand()` 实现，不新增 IPC channel。

### Root ViewModel

修改 `src/renderer/app/RootViewModel.ts`：

- 新增 `isUserManualOpen` 状态。
- 新增 `openUserManual()` 和 `closeUserManual()`。
- `handleMenuCommand('open-user-manual')` 时打开说明书。

### Renderer 视图

新增 `src/renderer/features/help/views/UserManualModal.tsx`：

- 使用 Ant Design `Modal`、`Typography`、`Anchor` 或轻量目录结构展示说明书。
- Modal 宽度控制在桌面可读范围内，正文区域内部滚动。
- 只展示用户操作说明，不展示开发命令、架构目录和测试信息。

修改 `src/renderer/features/stock-workspace/views/WorkspacePage.tsx`：

- 挂载 `UserManualModal`。
- 将 `root.isUserManualOpen` 和 `root.closeUserManual` 传给组件。

修改 `src/renderer/styles.css`：

- 增加说明书 Modal 的最大高度、滚动区域、段落间距和小屏适配样式。
